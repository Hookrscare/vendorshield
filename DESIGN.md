# VendorShield — The Reference Library

## Direction

An editorial reference library for people making considered decisions about third-party services. Dark vellum, warm light ink, muted sage and fine rules. The visual identity should feel like a carefully typeset technical publication, with one sculptural document object connecting the brand to its purpose.

## System

- Display: Newsreader, regular and italic. Large but measured, tighter leading. No all-caps hero.
- Body/UI: DM Sans. 16px body, 12px minimum supporting labels, 44px interactive targets.
- Colors: surface #171b17; ink #eceee5; secondary #b0b6a7; line #394235; sage #bccda4; raised surface #252d23.
- Layout: 1320px maximum, 48px desktop gutters / 22px mobile. Asymmetric editorial hero; numbered category index and ruled vendor list. No grid of interchangeable marketing cards.
- Geometry: fine rules, square edges, 3px control corners. No pill badges, neon shadows, generic gradient panels or decorative icon circles.
- Motion: CSS 3D layered documents respond to pointer, focus and activation. No continuous rendering loop or auto-rotating distraction. Row disclosures animate a short entrance; clear focus and hover states. Reduced motion removes 3D/entrance movement. Touch retains every functional control.
- Navigation: simple wordmark, a small public navigation set, and one workspace action. Mobile menu exposes all links. The vendor workspace uses a persistent numbered navigation rail on desktop and an explicit menu on mobile.
- Integrity: static directory records and certification labels remain explicitly unverified. Links are source references, not endorsements. No automatic-monitoring, security-verdict or customer-proof claims.

## Scope

Directory index, vendor details, public homepage, public capability page, shared navigation/footer, and all five vendor workspace routes (register/activity/settings and plan, exports, disclosure, team, unavailable analysis). SnapInspect's cloud workflow and Dispel's disabled detector remain unchanged. Expand the same language to other public pages in subsequent work; never restyle dense workspaces by global color overrides.

## Decisions

2026-09-20: Dark mode is the default for every visitor regardless of OS preference. CSS and server-rendered color-scheme metadata apply before hydration; no client theme switch or stored preference existed. Artwork uses dark layered surfaces with light ink.

2026-09-20: User requested an elegant, sober, authored redesign with purposeful 3D. Chose a document-library composition to tie the dimensional object to the actual directory instead of introducing an unrelated decorative globe or dashboard.

2026-09-20: Extended the reference-library direction to the authenticated workspace. Use ruled summaries and task-oriented records, not dashboard card grids. Forms and dialogs use visible labels, muted raised surfaces and restrained offset depth. Mobile records expose labeled fields without a sideways seven-column table. Product metrics describe user-maintained records; no compliance score is inferred from DPA status.
